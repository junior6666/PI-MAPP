> **描述**：给定一个非空二叉树的根节点 `root`，以数组的形式返回每一层节点的平均值。与实际答案相差 $10^{-5}$ 以内的答案可以被接受。

---

## 🧠 一、理解题意（小白友好）

- 输入：一棵二叉树的根节点。
- 输出：一个浮点数列表，每个元素是**某一层所有节点值的平均值**。
- 例如：
  ```
        3
       / \
      9  20
        /  \
       15   7
  ```
  第0层：[3] → 平均 = 3.0  
  第1层：[9, 20] → 平均 = (9+20)/2 = 14.5  
  第2层：[15, 7] → 平均 = 11.0  
  返回：`[3.0, 14.5, 11.0]`

关键点：**按层遍历（Level Order Traversal）** → 这就是典型的 **BFS（广度优先搜索）** 场景！

---

## ✅ 二、一般解法（BFS + 队列）—— 推荐给初学者

### 思路：
- 使用队列（`collections.deque`）进行层序遍历。
- 每次处理**当前层的所有节点**（通过记录当前队列长度）。
- 累加当前层的和，除以节点数得到平均值。

### Python 代码（标准 BFS）：
```python
from collections import deque

def averageOfLevels(root):
    if not root:
        return []
    
    queue = deque([root])
    result = []
    
    while queue:
        level_size = len(queue)  # 当前层有多少个节点
        level_sum = 0
        
        for _ in range(level_size):
            node = queue.popleft()
            level_sum += node.val
            
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(level_sum / level_size)
    
    return result
```

### ✅ 优点：
- 清晰直观，符合“层”的语义。
- 时间复杂度：O(n)，每个节点访问一次。
- 空间复杂度：O(w)，w 是树的最大宽度（最坏 O(n)）。

## 🔺 三、进阶解法（DFS + 深度记录）

虽然 BFS 更自然，但也可以用 DFS 实现，关键在于**记录每个节点的深度**，并把同一深度的值收集起来。

### 思路：
- 递归遍历树，同时传递当前深度 `depth`。
- 用两个列表（或字典）分别记录每层的**总和**和**节点数量**。
- 最后再计算平均值。

### Python 代码（DFS）：
```python
def averageOfLevels(root):
    sums = []   # 每层的总和
    counts = [] # 每层的节点数
    
    def dfs(node, depth):
        if not node:
            return
        if depth == len(sums):
            sums.append(0)
            counts.append(0)
        sums[depth] += node.val
        counts[depth] += 1
        
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    
    dfs(root, 0)
    return [s / c for s, c in zip(sums, counts)]
```

### ⚠️ 注意：
- 要确保 `sums` 和 `counts` 在访问 `depth` 前已扩展到该索引。
- DFS 的空间复杂度是 O(h)（h 是树高），但需要额外存储每层数据。

## 💼 四、面试中的最佳实践 & 常见问题

### ✅ 面试推荐解法：
- **首选 BFS 解法**，因为它直接对应“层”的概念，逻辑清晰，不容易出错。
- 如果面试官问：“能不能用 DFS？”，再展示 DFS 版本，体现你思维灵活。

### ❌ 常见错误 & 陷阱：

#### 错误 1：没有按“整层”处理，而是逐个节点入队出队
```python
# ❌ 错误示例（伪代码）
while queue:
    node = queue.popleft()
    # 直接算平均？不行！因为你不知道这一层还有多少节点
```
→ 必须用 `for _ in range(len(queue))` 来锁定当前层。

#### 错误 2：使用 `list.pop(0)` 代替 `deque.popleft()`
```python
queue = [root]
node = queue.pop(0)  # O(n) 时间！
```
→ `list.pop(0)` 是线性时间，会导致整体复杂度退化为 O(n²)。  
✅ 正确做法：用 `collections.deque`，`popleft()` 是 O(1)。

#### 错误 3：忽略浮点精度（但本题允许 1e-5 误差，Python 默认 float 足够）

## 🌲 一、什么是 DFS？

**DFS（Depth-First Search，深度优先搜索）** 是一种遍历或搜索树/图的策略：  
> **尽可能深地往下走，直到走不动了，再回退（回溯），尝试其他分支。**

想象你在走迷宫：
- 不是横着一层层扫（那是 BFS），
- 而是选一条路一直走到死胡同，再原路返回，找岔路口走另一条。

在二叉树中，常见的 DFS 遍历方式有：
- 前序（根 → 左 → 右）
- 中序（左 → 根 → 右）
- 后序（左 → 右 → 根）

但注意：**DFS 本身不天然“按层”处理**，所以我们要**主动记录深度**，才能把节点归到对应的层！

---

## 🧩 二、为什么 DFS 能用来求“每层平均值”？

虽然 DFS 是“纵向”走的，但只要我们在递归时**带上当前节点的深度（level/depth）**，就可以：

✅ **知道这个节点属于第几层**  
✅ **把同一层的所有节点值收集起来**

这就把“无序的 DFS 访问”转化成了“按层聚合”的能力！

---

## 🔍 三、核心思想（关键！）

我们需要两个容器：
1. `sums`：列表，`sums[i]` 表示第 `i` 层所有节点值的总和。
2. `counts`：列表，`counts[i]` 表示第 `i` 层有多少个节点。

然后通过 DFS 遍历每个节点，同时传入它的深度 `depth`：
- 如果这是第一次访问第 `depth` 层（即 `len(sums) == depth`），就往两个列表末尾追加新元素（初始化为 0）。
- 然后把当前节点的值加到 `sums[depth]`，计数 `counts[depth] += 1`。
- 递归访问左右子树，深度 +1。

最后，用 `sums[i] / counts[i]` 得到每层平均值。

## 📜 四、完整代码 + 逐行注释

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def averageOfLevels(root):
    sums = []    # 每层的总和，sums[0] 是第0层（根）的和
    counts = []  # 每层的节点数量

    def dfs(node, depth):
        # 递归终止条件：空节点直接返回
        if not node:
            return
        
        # 关键判断：如果当前深度等于列表长度，说明这是该层第一个节点！
        # 例如：depth=0，sums=[]（长度0）→ 需要初始化第0层
        if depth == len(sums):
            sums.append(0)    # 初始化该层总和为0
            counts.append(0)  # 初始化该层节点数为0
        
        # 把当前节点的值加到对应层
        sums[depth] += node.val
        counts[depth] += 1

        # 递归处理左右子树，深度+1
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    
    # 从根节点开始，深度为0
    dfs(root, 0)
    
    # 最后计算每层平均值
    return [s / c for s, c in zip(sums, counts)]
```

## ⚖️ 六、DFS vs BFS 对比（本题）

| 维度 | DFS 解法 | BFS 解法 |
|------|--------|--------|
| **直观性** | 需要理解“带深度的递归” | 直接按层处理，更直观 |
| **空间复杂度** | O(h)，h 是树高（递归栈） | O(w)，w 是最大宽度（队列） |
| **适用场景** | 树很深但很窄（如链状树） | 树很宽但不高 |
| **面试表现** | 展示递归和状态记录能力 | 展示对层序遍历的掌握 |
| **易错点** | 忘记初始化新层、深度传递错误 | 忘记锁定当前层大小、用 list.pop(0) |

> 💡 在完全二叉树中，BFS 队列可能存 n/2 个节点（最后一层），而 DFS 递归栈只存 log n 层。但在极端不平衡树（如只有右孩子），DFS 栈深度为 n，BFS 队列始终只有 1 个节点。

## ❓ 七、常见疑问解答（FAQ）

### Q1：为什么用 `if depth == len(sums)` 来判断是否要初始化？
因为 `sums` 列表的索引是从 0 开始的，长度为 L 时，最大有效索引是 L-1。  
当 `depth == len(sums)`，说明我们要访问的层还没被创建，需要 `append`。

### Q2：能不能用字典代替列表？
可以！比如：
```python
sums = {}
counts = {}
...
if depth not in sums:
    sums[depth] = 0
    counts[depth] = 0
```
但最后要按 `depth` 从小到大输出，所以还得排序 keys，不如列表自然有序。

### Q3：DFS 的遍历顺序会影响结果吗？
不会！因为我们只是**累加**，加法满足交换律。无论先左后右还是先右后左，总和和计数都一样。
