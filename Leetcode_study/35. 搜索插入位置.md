class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        if not nums:
            return 0
        for i in range(len(nums)):
            if target <= nums[i]:
                return i
        return len(nums)

## 🧩 一、题目再理解

> **输入**：一个**升序排列**的整数数组 `nums`，和一个目标值 `target`  
> **输出**：
> - 如果 `target` 在数组中 → 返回其**索引**
> - 如果不在 → 返回它**应该被插入的位置**（保持升序）

例如：
```python
nums = [1,3,5,6], target = 5 → 输出 2（找到了）
nums = [1,3,5,6], target = 2 → 输出 1（插在 1 和 3 之间）
nums = [1,3,5,6], target = 7 → 输出 4（插在末尾）
nums = [1,3,5,6], target = 0 → 输出 0（插在开头）
```

关键点：**数组已排序** → 暗示我们可以用**二分查找**！

## ✅ 三、正确解法：二分查找（O(log n)）

### 核心思想：
因为数组**有序**，我们每次比较中间元素：
- 如果 `nums[mid] == target` → 找到了，返回 `mid`
- 如果 `nums[mid] < target` → 说明 target 在右半边 → `left = mid + 1`
- 如果 `nums[mid] > target` → 说明 target 在左半边 → `right = mid - 1`

**即使没找到，循环结束时 `left` 就是插入位置！**

### 🎯 为什么是 `left`？

这是二分查找中最经典的“**插入位置**”结论。我们来直观理解：

- 二分查找过程中，`left` 始终指向“**可能插入的最左位置**”
- 当循环结束（`left > right`），`left` 刚好停在第一个 **大于等于 target** 的位置
- 这正是我们要插入的地方！

> 举个例子：`nums = [1,3,5,6]`, `target = 2`
> - 最终 `left = 1`, `right = 0` → 插入位置是 1 ✅

## 🧠 四、标准二分查找实现（推荐面试写法）

```python
from typing import List

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        
        # 循环结束时，left 就是插入位置
        return left
```

### ✅ 特点：
- 时间复杂度：**O(log n)**
- 空间复杂度：**O(1)**
- 处理了所有边界情况（空数组？开头？结尾？）
- 代码简洁，逻辑清晰，**面试官最爱**

> 🔔 注意：Python 中 `//` 是地板除，不会溢出（不像 Java/C++ 需要防 `mid = left + (right - left) // 2`）

## 🧪 七、完整可运行代码（带测试）

```python
from typing import List

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left

# 测试
if __name__ == "__main__":
    sol = Solution()
    print(sol.searchInsert([1,3,5,6], 5))  # 2
    print(sol.searchInsert([1,3,5,6], 2))  # 1
    print(sol.searchInsert([1,3,5,6], 7))  # 4
    print(sol.searchInsert([1,3,5,6], 0))  # 0
    print(sol.searchInsert([], 1))         # 0
```
