# PicLayouter - 图片布局管理工具

一个基于 PySide6 的桌面端图片网格布局工具，支持多张图片的可视化整理、实时预览和导出。

## ✨ 功能特性

### 核心功能
- 📁 **图片管理** - 支持拖拽上传、批量选择、清空删除
- 🎨 **智能布局** - 自动填充/固定行列模式，实时预览
- 📐 **精确控制** - 间距、对齐、内边距可自由调节
- 🖼️ **画布设置** - 自适应内容/自定义尺寸、背景颜色、透明背景
- 💾 **一键导出** - 导出为 PNG/JPG/BMP 格式，支持查看

### 便捷操作
- 🔍 **Ctrl + 滚轮** - 缩放画布（0.1x - 5.0x）
- ✋ **Ctrl/右键拖动** - 平移画布
- 🔄 **重置视图** - 一键恢复默认视图
- ↶↷ **撤销/重做** - 支持 20 步操作历史

## 🚀 快速开始

### 环境要求
- Python 3.8+
- PySide6

### 安装依赖
```bash
pip install PySide6
```

### 运行程序
```bash
# 方式 1：直接运行
python main_ui_pic_layouter.py

# 方式 2：使用启动脚本（Windows）
run.bat

# 打包
pyinstaller -F -w -i app.ico --add-data "app.ico;." --name="PicLayouter" main_ui_pic_layouter.py
```

## 📖 使用说明

### 1. 添加图片
- 点击 `📁 添加图片` 按钮
- 或直接拖拽图片文件到画布区域

### 2. 调整布局
- 点击 `⚙️ 高级设置` 展开布局选项
- 选择布局模式（自动填充/固定行列）
- 调节图片间距、对齐方式、内边距

### 3. 画布设置
- 默认启用 **自适应内容大小**
- 可切换为自定义画布尺寸
- 选择背景颜色或透明背景

### 4. 视图操作
- **缩放**：按住 `Ctrl` + 滚动鼠标滚轮
- **平移**：按住 `Ctrl + 左键` 或 `右键` 拖动
- **重置**：点击 `🔄 重置视图` 按钮

### 5. 导出图片
- 点击 `💾 导出图片` 按钮
- 文件名格式：`PicLayouter_YYYYMMDD_HHMMSS.png`
- 导出后可点击 `👁️ 查看图片` 预览
