# 💻 系统资源管理器 - 使用教程

## 📋 功能简介

这是一款伪装成"系统资源管理器"的AI面试辅助工具，支持快捷键截图、OCR识别、LLM智能分析，并可通过手机实时接收分析结果。

---

## ⌨️ 快捷键说明

### 快速分析模式（Alt + Z）只是流程上快 实际不快
**适用场景**：快速查看屏幕上的面试题目并获取答案 （30s左右 比较准确）

**工作流程**：
```
按下 Alt+Z → 全屏截图 → Kimi AI分析 → 结果推送到手机
```

**特点**：
- ⚡ 跳过OCR，直接调用视觉大模型（Kimi）
- 🚀 速度更快，适合有明确题目的场景
- 📸 自动截取整个屏幕

---

### OCR分析模式（Alt + X）
**适用场景**：需要精确识别文字后再分析

**工作流程**：
```
按下 Alt+X → 截图保存 → OCR文字识别 → LLM分析 → 结果推送到手机 （20s左右 还行）
```

**特点**：
- 🔍 先OCR提取文字，再调用文本大模型
- 📝 适合需要查看识别文本的场景
- ️ 可配置提示词和模型参数

---

## 📱 手机端使用

### 连接步骤

1. **启动WebSocket服务**（PC端自动启动）
   - 默认端口：`8765`
   
2. **手机浏览器访问**
   ```
   ws://[PC局域网IP]:8765
   ```
   示例：`ws://192.168.1.100:8765`

3. **查看实时状态**
   - ⏳ 待命
   - 📸 已触发截图
   - 🔍 OCR分析中
   - 🤖 LLM分析中
   - ✅ 已完成 (15.23s)

### 手机端功能
- 📜 **历史记录**：自动保存最近50条消息
- 📋 **代码复制**：一键复制代码块
- 🎨 **Markdown渲染**：完美显示代码高亮、列表、引用等

## ⚠️ 注意事项

### 1. 快捷键冲突
- 确保 `Alt+Z` 和 `Alt+X` 未被其他程序占用
- 如快捷键无效，可在"截图设置"中修改热键组合

### 2. 网络要求
- PC端和手机需在**同一局域网**内
- 防火墙需允许端口 `8765` 通行
- 如连接失败，检查手机配置中的IP地址

### 3. AI模型调用
- **主模型**：Kimi-K2.5（Moonshot API）
- **备用模型**：6个备选模型自动降级
  - Qwen3-Omni-30B
  - Qwen3-VL-8B/32B/235B
  - GLM-4.5V
  - Kimi-K2.5 (SiliconFlow)
- 主模型连续失败2次后自动切换备选模型

### 4. 耗时计算
- 总耗时从**快捷键按下时刻**开始计算
- 快速模式通常更快（跳过OCR）
- 网络延迟会影响实际体验

### 5. 隐私安全
- 截图会保存到 `./screenshots/` 目录
- API Key 已加密存储
- 建议定期清理截图文件

### 6. 系统托盘
- 最小化窗口后自动隐藏到托盘
- 双击托盘图标恢复窗口
- 右键托盘菜单可退出程序

## 🐛 常见问题

### Q: 快捷键无反应？
A: 检查是否有其他程序占用了快捷键，或在设置中修改热键。

### Q: 手机无法连接？
A: 
1. 确认PC端WebSocket服务已启动（状态栏显示"已连接"）
2. 检查IP地址是否正确（手机配置中可查看）
3. 关闭防火墙或添加端口例外

### Q: 分析结果不准确？
A: 
1. 确保截图中题目清晰可见
2. 调整提示词模板
3. 尝试切换不同模型

### Q: 窗口黑色边框？
A: 已修复。如仍有问题，尝试调整窗口大小。
