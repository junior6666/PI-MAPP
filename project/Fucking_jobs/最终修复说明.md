# 窗口闪烁和托盘图标问题 - 最终修复方案

## 🔧 已实施的修复

### 1. **完全禁用资源监控定时器**
```python
# 之前：每10秒更新一次（仍会闪烁）
self.resource_timer.start(10000)

# 现在：完全禁用（注释掉）
# self.resource_timer = QTimer()
# self.resource_timer.timeout.connect(self.update_resource_info)
# self.resource_timer.start(10000)
```

**原因**: 打包后 PySide6 的定时器触发会导致整个窗口重绘，造成闪烁。

---

### 2. **优化窗口渲染属性**
```python
# 启用不透明绘制事件
self.setAttribute(Qt.WA_OpaquePaintEvent, True)
# 禁用删除时关闭
self.setAttribute(Qt.WA_DeleteOnClose, False)
# 设置最小尺寸
self.setMinimumSize(800, 600)
```

---

### 3. **修复托盘图标加载**
```python
def _get_resource_path(self, relative_path):
    """获取资源文件的绝对路径（兼容打包环境）"""
    if getattr(sys, 'frozen', False):
        # 打包后的环境
        base_path = sys._MEIPASS
    else:
        # 开发环境
        base_path = os.path.abspath(".")
    return os.path.join(base_path, relative_path)

# 使用
icon_path = self._get_resource_path("icon.ico")
if os.path.exists(icon_path):
    self.tray_icon.setIcon(QIcon(icon_path))
```

**原因**: 打包后文件在临时目录（`sys._MEIPASS`），需要特殊处理路径。

---

### 4. **延迟初始化托盘**
```python
# 之前：立即初始化
self.init_system_tray()

# 现在：延迟2秒，等待UI完全加载
QTimer.singleShot(2000, self.init_system_tray)
```

---

### 5. **禁用 UPX 压缩**
```bash
--noupx
```

**原因**: UPX 压缩可能导致某些 DLL 加载异常，影响渲染稳定性。
