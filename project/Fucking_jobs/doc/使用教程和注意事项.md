# 💻 系统资源管理器 - 使用教程

## 📋 功能简介

这是一款伪装成"系统资源管理器"的AI面试辅助工具，支持快捷键截图、OCR识别、LLM智能分析，并可通过手机实时接收分析结果。

---

## ⌨️ 快捷键说明

### 🚀 工作流快捷键

#### 自动写入完整流程（Alt + S）⭐ 新功能
**适用场景**：将AI分析结果整理为面试代码并自动输入到IDE（约50-70秒）

**工作流程**：
```
按下 Alt+S → 检查API结果 → LLM代码整理 → 保存到文件 → 复制到剪切板 → 自动写入目标窗口
```

**特点**：
- 📝 **智能整理**：调用LLM优化代码，去除注释、简化变量名
- 💾 **自动保存**：保存为纯代码txt文件（无Markdown标记）
- 📋 **复制剪切板**：同时复制到剪切板，方便手动粘贴
- ⌨️ **自动输入**：模拟键盘逐行输入代码到目标窗口
- ⏸️ **暂停控制**：按 Alt+L 可暂停/恢复写入
- 📱 **实时状态**：手机端显示各阶段耗时
- ⚙️ **高度可配置**：延迟、思考时间、错误率、换行率均可调整

**使用步骤**：
1. 先执行 Alt+X 或 Alt+Z 获取API分析结果
2. 切换到需要输入代码的IDE窗口
3. 按下 Alt+S 启动自动写入流程
4. 等待5秒后系统自动开始输入
5. 如需暂停，按 Alt+L；继续按 Alt+L

**配置项**（在 Case3 标签页设置）：
- ⏱️ **字符间隔**：0.01s ~ 0.50s（滑块调节）
- 🤔 **思考时间**：最小值 ~ 最大值（随机延迟模拟思考）
- ❌ **打字错误率**：0% ~ 100%（模拟真实打错字并退格修正）
- ↩️ **长行换行率**：0% ~ 100%（超长行随机换行的概率）
- 📋 **复制时机**：整理后立即复制 / 写入完成后复制（默认）
- 🚀 **快捷模式**：熟练模式(0.02s)、新手模式(0.15s)
- 🧠 **思考模式**：快速思考(0.5~1.0s)、正常思考(1.0~2.0s)、深度思考(2.0~3.5s)

**手机端状态**：
- 📝 整体代码中 (计时)
- ⌨️ 自动写入中 (计时)
- ⏸️ 暂停写入
- ▶️ 恢复写入
- ✅ 写入完成 (总耗时: XX.XXs)

#### 快速分析模式（Alt + Z）
**适用场景**：快速查看屏幕上的面试题目并获取答案（约30秒，准确率高）

**工作流程**：
```
按下 Alt+Z → 全屏截图 → Kimi AI分析 → 结果推送到手机
```

**特点**：
- ⚡ 跳过OCR，直接调用视觉大模型（Kimi）
- 🎯 适合有明确题目的场景
- 📸 自动截取整个屏幕

---

#### OCR分析模式（Alt + X）
**适用场景**：需要精确识别文字后再分析（约20秒，速度较快）

**工作流程**：
```
按下 Alt+X → 截图保存 → OCR文字识别 → LLM分析 → 结果推送到手机
```

**特点**：
- 🔍 先OCR提取文字，再调用文本大模型
- 📝 可查看中间识别结果
- ⚙️ 可配置提示词和模型参数

### 🔄 模型切换快捷键

#### OCR模型切换（Alt + 1）
在 DeepSeek-OCR 和 EasyOCR 之间切换：
- **DeepSeek-OCR**：云端API，识别准确率高，依赖网络
- **EasyOCR**：本地模型，离线可用，速度稳定

**使用方法**：
```
按下 Alt+1 → 切换模型 → 下次截图使用新模型
```

**状态提示**：
- 终端显示：`🔄 OCR 模型已切换: XXX → YYY`
- 状态栏显示：`OCR 模型已切换为: YYY`
- 手机端推送：`[STATUS:OCR模型切换为YYY]`

---

#### Kimi主模型切换（Alt + 2）
在 Kimi-K2.5 和 QwenA3B 之间双向切换：
- **Kimi-K2.5**：Moonshot API，默认主模型
- **QwenA3B**：Qwen3-Omni-30B，SiliconFlow平台

**使用方法**：
```
按下 Alt+2 → 切换模型 → 下次快速分析使用新模型
```

---

#### 后备模型快速设置（Alt + 3 ~ Alt + 7）
直接将指定模型设置为主模型，灵活应对不同场景：

| 快捷键 | 模型名称 | 特点 | 适用场景 |
|--------|----------|------|----------|
| **Alt+3** | Qwen-VL-8B | 轻量级，速度快 ⚡ | 日常练习，快速响应 |
| **Alt+4** | Qwen-VL-32B | 中等规模，平衡 🎯 | 一般面试，性价比 |
| **Alt+5** | Qwen-VL-235B | 大规模，高精度 🧠 | 重要面试，复杂题目 |
| **Alt+6** | GLM-4.5V | 智谱GLM系列 🔮 | 备选方案，多样化 |
| **Alt+7** | Kimi-K2.5(SF) | SiliconFlow平台 🌟 | Kimi备用通道 |

**使用方法**：
```
按下 Alt+3~7 → 立即生效 → 下次快速分析使用新模型
```

**示例**：
```bash
# 切换到大规模高精度模型
按下 Alt+5
终端输出: 🔄 Kimi 主模型已设置为: Qwen3-VL-235B-A22B-Instruct
状态栏: Kimi 主模型已设置为: Qwen3-VL-235B-A22B-Instruct

# 执行快速分析
按下 Alt+Z
🤖 Qwen3-VL-235B-A22B-Instruct 请求中...
✅ Qwen3-VL-235B-A22B-Instruct 完成 (12.34s)
```

**技术说明**：
- 所有后备模型均使用 SiliconFlow API
- 切换时自动重置失败计数和成功计数
- 不影响自动降级策略（连续失败2次仍会切换）
- 程序重启后恢复默认主模型（Kimi-K2.5）

#### 切换下一张手机照片（Alt + C）⭐ 新功能
**适用场景**：手机拍照模式下，循环切换同一批次的多张照片

**使用方法**：
```
按下 Alt+C → 切换到下一张照片 → 自动触发截图流程
```

**特点**：
- 📱 **仅手机模式有效**：需在「设置」标签页选择"手机物理拍照"
- 🔄 **循环切换**：到达最后一张后自动回到第一张
- 📊 **实时显示**：终端显示当前照片序号（如：第 2/5 张）
- ⚡ **自动触发**：切换后立即执行 Alt+X 或 Alt+Z 工作流

**使用步骤**：
1. 确保已通过 WebSocket 从手机发送多张照片
2. 在「设置」标签页选择"手机物理拍照"并保存
3. 按下 Alt+C 循环切换照片
4. 每张照片会自动触发分析流程

**手机端批量上传**：
- 手机浏览器访问 `ws://[PC IP]:8765`
- 点击"📤"按钮选择多张照片
- 系统自动创建批次文件夹（如：`20260424_143025_5张`）

## ⚠️ 注意事项

### 1. 快捷键冲突
- 确保 `Alt+Z` 和 `Alt+X` 未被其他程序占用
- 如快捷键无效，可在"截图设置"中修改热键组合

### 2. 网络要求
- PC端和手机需在**同一局域网**内
- 防火墙需允许端口 `8765` 通行
- 如连接失败，检查手机配置中的IP地址

### 3. AI模型调用
- **主模型**：Kimi-K2.5（Moonshot API）
- **备用模型**：6个备选模型自动降级
  - Qwen3-Omni-30B
  - Qwen3-VL-8B/32B/235B
  - GLM-4.5V
  - Kimi-K2.5 (SiliconFlow)
- 主模型连续失败2次后自动切换备选模型

### 4. 耗时计算
- 总耗时从**快捷键按下时刻**开始计算
- 快速模式通常更快（跳过OCR）
- 网络延迟会影响实际体验

### 5. 隐私安全
- 截图会保存到 `./screenshots/` 目录
- API Key 已加密存储
- 建议定期清理截图文件

### 6. 系统托盘
- 最小化窗口后自动隐藏到托盘
- 双击托盘图标恢复窗口
- 右键托盘菜单可退出程序

### 7. 图片来源设置（⭐ 新功能）

**位置**：帮助标签页 → ⚙️ 设置 → 图片来源设置

**两种模式**：
- 💻 **PC屏幕截图**（默认）：通过 mss 库截取屏幕，快速稳定，适合日常练习
- 📱 **手机物理拍照**：通过 WebSocket 接收手机照片，更准确，适合正式面试

**配置方法**：
1. 打开「帮助」标签页
2. 切换到「⚙️ 设置」子标签
3. 选择图片来源模式
4. 点击「💾 保存图片来源配置」

**使用建议**：
- 日常练习：使用 PC 截图，方便快捷
- 正式面试：使用手机拍照，清晰度高，避免屏幕反光干扰

## 🐛 常见问题

### Q: 快捷键无反应？
A: 
1. 检查是否有其他程序占用了快捷键
2. 尝试关闭输入法或使用英文输入法
3. 在"截图设置"中修改热键组合
4. 重启程序重新注册热键

### Q: 手机无法连接？
A: 
1. 确认PC端WebSocket服务已启动（状态栏显示"已连接"）
2. 检查IP地址是否正确（手机配置中可查看）
3. 关闭防火墙或添加端口例外
4. 确保手机和PC在同一WiFi网络下

### Q: 分析结果不准确？
A: 
1. 确保截图中题目清晰可见
2. 调整提示词模板（在主页标签页编辑）
3. 尝试切换不同模型（Alt+3~7）
4. 重要面试建议使用大规模模型（Alt+5）

### Q: 如何选择合适的模型？
A: 
- **日常练习**：Alt+3 (Qwen-VL-8B)，速度快
- **一般面试**：Alt+4 (Qwen-VL-32B)，平衡性好
- **重要面试**：Alt+5 (Qwen-VL-235B)，准确率高
- **网络不佳**：Alt+1 切换到 EasyOCR，Alt+6 使用 GLM
- **追求速度**：Alt+2 切换到 Kimi-K2.5

### Q: 如何使用手机拍照模式？
A: 
1. 手机浏览器访问 `ws://[PC IP]:8765`
2. 点击"📤"按钮选择多张照片上传
3. PC端打开「帮助」→「⚙️ 设置」→ 选择"手机物理拍照"
4. 点击"💾 保存图片来源配置"
5. 按 Alt+C 循环切换照片进行分析
6. 每次切换都会自动触发 Alt+X 或 Alt+Z 工作流

### Q: 如何配置自动写入的参数？
A: 
1. 打开「帮助」→「⌨️ Case3 (Alt+S)」标签页
2. 调整以下参数：
   - **字符间隔**：拖动滑块（0.01s~0.50s）
   - **思考时间**：设置最小值和最大值
   - **打字错误率**：模拟真实打错字的概率（0~100%）
   - **长行换行率**：超长行随机换行的概率（0~100%）
   - **复制时机**：选择"整理后立即复制"或"写入完成后复制"
3. 可使用快捷模式：
   - 🚀 熟练模式：0.02s 快速输入
   - 🐢 新手模式：0.15s 慢速输入
   - ⚡ 快速思考：0.5~1.0s
   - 🎯 正常思考：1.0~2.0s（默认）
   - 🤔 深度思考：2.0~3.5s
4. 点击"💾 保存配置"按钮

### Q: 复制时机有什么区别？
A: 
- **整理后立即复制**：代码整理完成后就复制到剪切板，适合需要手动粘贴的场景
- **写入完成后复制**（默认）：自动输入完成后才复制，作为备用方案，防止输入失败时可手动粘贴

### Q: OCR识别失败怎么办？
A: 
1. 按 Alt+1 切换到 EasyOCR 本地模型
2. 检查网络连接（DeepSeek-OCR需要联网）
3. 确保截图清晰，文字可读
4. 系统会自动降级，连续失败2次后自动切换

### Q: 窗口黑色边框？
A: 已修复。如仍有问题，尝试调整窗口大小或重启程序。

### Q: 程序占用内存过高？
A: 
1. OCR引擎采用单例模式，首次加载后会常驻内存
2. 长时间运行建议定期重启程序
3. 退出程序时会正确清理所有资源
4. 任务中断时会立即释放大对象

### Q: 如何查看当前使用的模型？
A: 
1. 终端会显示每次调用的模型名称
2. 状态栏会显示最近的操作
3. 手机端会收到模型切换通知
4. 分析结果开头会标注使用的模型
