# Case3 自动写入配置功能说明

## 🎯 功能概述

新增了 **Case3 (Alt+S)** 标签页，用于配置自动写入功能的参数：
1. **输入延迟调节** - 可调整字符输入间隔（0.01s ~ 0.50s）
2. **思考时间范围** - 可设置关键行前后的随机暂停时间（0.1s ~ 10.0s）
3. **代码整理提示词** - 可自定义AI代码整理的规则和风格

## 📋 使用方法

### 访问配置界面
1. 打开程序主窗口
2. 点击"帮助"标签页
3. 选择"⌨️ Case3 (Alt+S)"标签

### 调整输入延迟
- **滑块范围**：0.01s ~ 0.50s
- **默认值**：0.05s
- **操作方式**：拖动滑块即可实时调整
- **显示效果**：右侧会实时显示当前延迟值（如：0.05s）

### 编辑代码整理提示词
- **编辑区域**：多行文本编辑器
- **默认提示词**：已预置面试代码整理规则
- **保存方式**：点击"💾 保存提示词"按钮
- **配置文件**：自动保存到 `case3_config.json`

### 调整思考时间范围
- **最小值**：0.1s ~ 10.0s，默认 1.0s
- **最大值**：0.1s ~ 10.0s，默认 2.0s
- **作用位置**：if/for/while/def/return/else等关键字前后
- **效果**：模拟真实面试中的思考停顿，使输入更自然

## ⚙️ 配置参数说明

### 延迟参数（delay）
| 延迟值 | 适用场景 | 特点 |
|--------|---------|------|
| 0.01~0.03s | 快速输入 | 适合熟练场景，速度快但可能不稳定 |
| 0.05~0.10s | 正常速度 | 平衡速度和稳定性，推荐使用 |
| 0.15~0.30s | 慢速输入 | 适合需要观察的场景，更稳定 |
| 0.30~0.50s | 极慢速 | 调试或特殊需求 |

### 提示词配置
提示词用于指导AI如何整理代码，包含以下要素：
- **解法选择**：保留最优解法
- **代码规范**：变量命名、注释处理等
- **输出格式**：Markdown代码块格式
- **风格要求**：模拟面试环境下的书写风格

### 思考时间配置
思考时间是指在输入特定关键字（如 if、for、return 等）前后添加的随机暂停时间：
- **作用**：模拟程序员在写代码时的思考过程
- **应用场景**：
  - 条件判断（if/elif/else）
  - 循环语句（for/while）
  - 函数定义（def）
  - 返回语句（return）
- **随机性**：每次暂停时间在最小值和最大值之间随机选择

## 💾 配置持久化

### 自动加载
- 程序启动时自动加载上次保存的配置
- 如果配置文件不存在，使用默认配置

### 手动保存
1. 调整延迟滑块到期望值
2. 设置思考时间范围（最小值和最大值）
3. 编辑提示词内容
4. 点击"💾 保存提示词"按钮
5. 系统会弹出确认对话框

## 🔗 与其他功能的关联

### CodeOrganizeWorker
- 使用UI中配置的提示词进行代码整理
- 如果没有自定义提示词，使用默认提示词

### AutoTypeWorker
- 使用UI中配置的delay参数控制输入速度
- 使用UI中配置的think_time_min和think_time_max控制思考时间
- 每次触发Alt+S时读取最新的配置值

## 🎮 快捷键

| 快捷键 | 功能 |
|--------|------|
| Alt + S | 启动自动写入流程（使用配置的delay、think_time和提示词） |
| Alt + L | 暂停/恢复自动写入 |

## 🐛 故障排查

### 问题1: 延迟调整不生效
**原因**: 配置未正确保存  
**解决**: 确保点击了"保存提示词"按钮，检查case3_config.json文件是否存在

### 问题2: 提示词修改后没有变化
**原因**: 代码整理时使用的是旧提示词  
**解决**: 重新启动程序或重新触发Alt+S工作流

### 问题3: 配置文件加载失败
**原因**: JSON格式错误或文件损坏  
**解决**: 删除case3_config.json文件，程序会使用默认配置

## 📊 最佳实践

1. **初次使用**：保持默认配置（delay=0.05s, think_time=1.0~2.0s），观察效果
2. **速度优化**：根据实际输入稳定性逐步调整delay值
3. **思考时间**：
   - 快速模式：0.5~1.0s，适合熟练场景
   - 正常模式：1.0~2.0s，推荐配置
   - 慢速模式：2.0~3.0s，更像真实思考
4. **提示词定制**：根据个人编码风格和需求调整提示词
5. **定期备份**：重要配置建议备份case3_config.json文件
