# 托盘图标使用说明

## 📌 当前状态

程序已启用系统托盘功能，启动时会：
1. ✅ 默认隐藏主窗口
2. ✅ 在系统托盘显示图标
3. ✅ 弹出提示消息告知用户

## 🎨 自定义托盘图标（可选）

如果需要自定义托盘图标，请按以下步骤操作：

### 方法1：使用 PNG 图标

1. 准备一个 32x32 或 64x64 的 PNG 图片
2. 将图片命名为 `tray_icon.png`
3. 放在与 `main_app.py` 同目录下
4. 修改 `main_app.py` 第 710 行：

```python
# 取消注释并修改为：
self.tray_icon.setIcon(QIcon("tray_icon.png"))
```

### 方法2：使用 ICO 图标（Windows 推荐）

1. 准备一个 .ico 格式的图标文件（支持多尺寸）
2. 将文件命名为 `icon.ico`
3. 放在与 `main_app.py` 同目录下
4. 修改代码：

```python
self.tray_icon.setIcon(QIcon("icon.ico"))
```

### 方法3：使用内置图标

如果不想使用自定义图标，可以保持当前状态，系统会使用默认图标。

## 💡 托盘功能说明

### 右键菜单
- **📺 显示窗口** - 显示主界面
- **🚪 退出程序** - 完全退出应用

### 双击托盘图标
- 切换窗口显示/隐藏状态

### 点击关闭按钮
- 不会真正退出，而是最小化到托盘
- 会弹出提示消息

### 完全退出
- 通过托盘菜单选择"退出程序"
- 或在任务管理器中结束进程

## 🔧 如需恢复显示窗口启动

如果希望程序启动时直接显示窗口，修改 `main_app.py` 第 813 行：

```python
# 将这行：
window.hide()

# 改为：
window.show()
```

## ⚙️ 高级配置

### 修改提示消息持续时间

在 `init_system_tray()` 方法中修改：

```python
self.tray_icon.showMessage(
    "标题",
    "内容",
    QSystemTrayIcon.Information,
    3000  # 毫秒数，这里是3秒
)
```

### 禁用托盘提示消息

注释掉 `init_system_tray()` 中的 showMessage 调用即可。
