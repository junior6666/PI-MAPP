# 自动写入功能使用说明

## 📋 功能概述

按下 **Alt+S** 快捷键后，系统将自动执行以下完整流程：

1. **代码整理** - 调用LLM API对Kimi/LLM的分析结果进行整理优化
2. **保存文件** - 将整理后的代码保存为txt文件
3. **自动写入** - 模拟键盘输入，将代码自动写入到目标窗口

## 🎯 使用步骤

### 第一步：执行截图分析工作流

首先需要执行 Case1 (Alt+X) 或 Case2 (Alt+Z) 工作流，获取API分析结果：

- **Case1 (Alt+X)**: 截图 → OCR识别 → LLM分析
- **Case2 (Alt+Z)**: 截图 → Kimi视觉模型直接分析

### 第二步：按下 Alt+S 启动自动写入

当API分析完成后，按下 **Alt+S** 快捷键，系统将：

1. ✅ 检测是否有可用的API结果（优先使用Kimi结果，备选LLM结果）
2. 📝 调用LongCat API进行代码整理
3. 💾 保存整理后的代码到 `./code_output/interview_code_YYYYMMDD_HHMMSS.txt`
4. ⌨️ 启动自动写入流程

### 第三步：切换到目标窗口

系统会提示"请在3秒内切换到目标窗口..."，此时：
- 快速切换到需要输入代码的目标窗口（如IDE、编辑器等）
- 确保输入法已切换到英文模式（系统会自动检测并切换）

### 第四步：等待自动写入完成

系统会自动逐行输入代码，过程中可以：
- **暂停/恢复**: 按 **Alt+L** 暂停或恢复写入
- **查看进度**: 状态栏显示当前输入行数
- **查看耗时**: 手机端实时显示各阶段耗时

## 📱 手机端状态显示

手机浏览器会实时显示以下状态：

| 状态 | 说明 | 计时 |
|------|------|------|
| 📝 整体代码中 | 正在调用LLM整理代码 | ✅ 计时 |
| ⌨️ 自动写入中 | 正在自动输入代码 | ✅ 计时 |
| ⏸️ 暂停写入 | 写入已暂停 | ❌ 停止计时 |
| ▶️ 恢复写入 | 恢复写入 | ✅ 继续计时 |
| ✅ 写入完成 | 全部完成 | 显示总耗时 |

## 🔧 技术细节

### 代码整理规则

整理的提示词要求：
- **解法选择**: 仅保留最经典/最优的解法
- **去噪**: 删除所有注释和多余空行
- **命名**: 使用极简变量名（x, y, k, v, i, j等）
- **风格**: 模拟面试高压环境下的极简风格
- **输出**: 只输出Markdown代码块，无其他说明

### 自动写入特性

- **智能过滤**: 自动识别并跳过Markdown代码块标记（```python 和 ```）
- **智能换行**: 长行有一定概率触发额外换行，模拟人工输入
- **思考延迟**: 每行输入后有0.5秒固定延迟
- **Home键处理**: 检测到'return'关键字时自动回到行首
- **英文输入**: 自动检测并切换到英文输入模式

## ⚠️ 注意事项

1. **必须先执行工作流**: 如果没有API结果，Alt+S不会生效
2. **3秒切换时间**: 按下Alt+S后有3秒时间切换到目标窗口
3. **英文输入**: 虽然系统会自动切换，但建议提前确认输入法状态
4. **不要中断**: 写入过程中尽量避免手动操作，以免干扰
5. **暂停功能**: 如需临时暂停，按Alt+L即可

## 🔍 故障排查

### 问题1: 按下Alt+S没有反应
**原因**: 没有可用的API结果  
**解决**: 先执行Alt+X或Alt+Z工作流

### 问题2: 代码写入位置不对
**原因**: 3秒内未切换到目标窗口  
**解决**: 重新按Alt+S，并在3秒内快速切换

### 问题3: 输入的是中文而非代码
**原因**: 输入法未切换到英文  
**解决**: 系统会自动尝试切换，也可手动按Alt+Shift

### 问题4: 写入速度太快/太慢
**原因**: 默认延迟为0.05秒/字符  
**解决**: 修改 `AutoTypeWorker` 的 `delay` 参数

## 📊 性能参考

- **代码整理**: 约3-8秒（取决于API响应速度）
- **自动写入**: 约30-60秒（取决于代码行数）
- **总耗时**: 约40-70秒

示例输出：
```
✅ 自动写入完成! (写入耗时: 45.23s, 总耗时: 52.67s)
```

## 🚀 高级用法

### 自定义整理提示词

修改 `CodeOrganizeWorker._organize_code()` 方法中的 `system_prompt` 变量，可自定义整理规则。

### 调整写入速度

修改 `main_app.py` 中 `start_auto_type()` 方法的 `delay` 参数：
```python
self.auto_type_worker = AutoTypeWorker(
    code_file_path=self.code_file_path,
    delay=0.05  # 调整为0.1可减慢速度
)
```

### 修改保存目录

修改 `CodeOrganizeWorker` 初始化时的 `save_dir` 参数：
```python
self.code_organize_worker = CodeOrganizeWorker(
    kimi_result=self.kimi_result,
    llm_result=self.llm_result,
    save_dir="./my_custom_dir"  # 自定义目录
)
```
