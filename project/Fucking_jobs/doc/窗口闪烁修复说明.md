# 窗口闪烁问题修复说明

## 🔍 问题原因分析

打包后的程序窗口频繁闪烁，主要由以下原因导致：

### 1. **资源监控定时器刷新过频**
- 原来每 2 秒更新一次 UI
- 每次更新都会触发大量控件重绘
- 打包后渲染效率降低，导致明显闪烁

### 2. **缺少双缓冲机制**
- PySide6 默认可能未启用双缓冲
- 直接绘制到屏幕会导致闪烁

### 3. **CPU 使用率检测阻塞**
- `psutil.cpu_percent(interval=0.1)` 是阻塞调用
- 每次调用等待 0.1 秒，影响 UI 响应

### 4. **不必要的组件更新**
- 即使某些标签页不可见，仍在更新
- 浪费资源并增加闪烁

---

## ✅ 已实施的修复方案

### 修复 1: 启用双缓冲和渲染优化

```python
def __init__(self):
    super().__init__()
    
    # 启用双缓冲，减少闪烁
    self.setAttribute(Qt.WA_PaintOnScreen, False)
    self.setAttribute(Qt.WA_NoSystemBackground, False)
    self.setAutoFillBackground(True)
```

**效果**: 启用双缓冲机制，先在内存中绘制再一次性显示到屏幕。

---

### 修复 2: 降低资源监控刷新频率

```python
# 修改前
self.resource_timer.start(2000)  # 每2秒更新

# 修改后
self.resource_timer.start(5000)  # 每5秒更新（减少60%刷新）
```

**效果**: 大幅减少 UI 重绘次数，从每分钟 30 次降到 12 次。

---

### 修复 3: 使用非阻塞 CPU 检测

```python
# 修改前
cpu_percent = psutil.cpu_percent(interval=0.1)  # 阻塞 0.1 秒

# 修改后
cpu_percent = psutil.cpu_percent(interval=None)  # 非阻塞，立即返回
```

**效果**: 消除阻塞延迟，UI 响应更流畅。

---

### 修复 4: 条件更新不可见组件

```python
# 修改前
self.update_process_table()      # 无论是否可见都更新
self.update_disk_info()          # 无论是否可见都更新

# 修改后
if hasattr(self, 'perf_table'):
    self.update_process_table()  # 只在存在时更新
    
if hasattr(self, 'disk_table'):
    self.update_disk_info()      # 只在存在时更新
```

**效果**: 避免更新未初始化的组件，减少无效绘制。

---

### 修复 5: 启用硬件加速

```python
def main():
    # 启用高 DPI 缩放
    QApplication.setHighDpiScaleFactorRoundingPolicy(
        Qt.HighDpiScaleFactorRoundingPolicy.PassThrough
    )
    
    app = QApplication(sys.argv)
    
    # 优化渲染性能
    app.setAttribute(Qt.AA_UseSoftwareOpenGL, False)  # 使用硬件加速
```

**效果**: 利用 GPU 加速渲染，减轻 CPU 负担。

---

### 修复 6: 排除不必要模块

```bash
--exclude-module=tkinter ^
--exclude-module=matplotlib ^
--exclude-module=scipy ^
```

**效果**: 减小程序体积，加快启动速度。

## ❓ 常见问题

### Q1: 为什么打包后会闪烁，源代码运行时不会？

**A**: PyInstaller 打包后：
- 资源从临时目录加载，路径更长
- 缺少开发环境的优化配置
- 单文件模式需要解压到临时目录
- 渲染管线可能不同

### Q2: 能否完全消除闪烁？

**A**: 可以接近完全消除，但需要权衡：
- 降低刷新频率 → 数据不够实时
- 禁用资源监控 → 失去监控功能
- 使用 onedir 模式 → 文件更多

当前方案已达到最佳平衡点。

### Q3: 其他电脑也会闪烁吗？

**A**: 取决于硬件配置：
- **高性能电脑**: 可能不明显
- **集成显卡**: 可能较明显
- **老旧电脑**: 建议使用 onedir 模式

### Q4: 如何判断是否是刷新频率导致的？

**A**: 临时禁用定时器测试：

```python
# 在 init_ui() 中注释这行
# self.resource_timer.start(5000)
```

如果不闪烁了，说明是刷新频率问题。

## 🔧 技术细节

### Qt 渲染机制

```
传统渲染（闪烁）:
UI 更新 → 清除屏幕 → 绘制新内容 → 显示

双缓冲渲染（流畅）:
UI 更新 → 绘制到内存缓冲区 → 一次性复制到屏幕
```

### PyInstaller 影响

```
源代码运行:
Python 解释器 → 直接加载模块 → 原生渲染

打包后运行:
Bootloader → 解压到临时目录 → 加载模块 → 可能降级渲染
```
