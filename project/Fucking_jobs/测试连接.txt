========================================
WebSocket 连接调试指南
========================================

【快速开始 - 电脑浏览器测试】

1. 启动 PySide6 应用
   - 运行: python main_app.py
   - 点击"启动 WebSocket 服务"按钮
   - 确认终端显示: "WebSocket 服务器已启动!"

2. 在浏览器中打开 phone.html
   - 直接双击 phone.html
   - 或拖到浏览器窗口

3. 点击"🖥️ 本地测试"按钮
   - 自动填充 127.0.0.1:8765
   - 自动尝试连接

4. 查看连接状态
   ✅ 成功: 状态显示"✅ 已连接"，消息区显示欢迎信息
   ❌ 失败: 查看消息区的错误提示


【常见问题排查】

问题1: 连接立即失败
原因: WebSocket 服务未启动
解决: 
  - 检查 PySide6 应用是否运行
  - 确认已点击"启动 WebSocket 服务"
  - 查看终端是否有错误信息

问题2: 连接超时
原因: 防火墙阻止
解决:
  - Windows 防火墙 → 允许 Python 通过
  - 或临时关闭防火墙测试

问题3: 地址被拒绝
原因: 端口被占用
解决:
  - 更换端口号（如 9000）
  - 重启 WebSocket 服务


【手机真机测试】

1. 确保手机和电脑在同一 WiFi

2. 查看电脑局域网 IP
   - 程序终端会显示: ws://218.194.45.229:8765
   - 或 CMD 输入: ipconfig → 查看 IPv4 地址

3. 手机访问 phone.html
   方式A: 发送文件到手机，用浏览器打开
   方式B: 搭建 HTTP 服务器
     CMD 运行:
     cd H:\pycharm_project\github_projects\PI-MAPP\project\Fucking_jobs
     python -m http.server 8080
     
     手机浏览器访问:
     http://218.194.45.229:8080/phone.html

4. 配置连接
   - 点击"⚙️ 配置"
   - IP: 218.194.45.229 (你的局域网IP)
   - 端口: 8765
   - 保存配置

5. 点击"连接"


【调试技巧】

1. 打开浏览器开发者工具
   - 按 F12
   - 切换到 Console 标签
   - 查看详细日志

2. 观察 PC 端终端输出
   [+] 手机已连接: 127.0.0.1  ← 连接成功
   [-] 手机断开               ← 连接断开

3. 测试消息发送
   - PC 端点击"发送结果到手机"
   - 手机应该立即收到消息


【连接地址说明】

电脑浏览器测试:
  ws://127.0.0.1:8765         ← 推荐，最简单
  ws://localhost:8765          ← 也可以

手机真机连接:
  ws://218.194.45.229:8765    ← 替换为你的实际IP


【端口说明】

默认端口: 8765
可修改范围: 1024-65535
如果冲突，在 PySide6 应用中修改端口号
