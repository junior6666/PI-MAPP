# Alt+Z 快速分析功能说明

## 🚀 功能概述

新增了 **Alt+Z** 快捷键工作流，实现一键完成以下操作：
1. **自动截图** - 截取当前屏幕
2. **Kimi AI 分析** - 调用 Kimi API 直接分析图片内容
3. **自动发送到手机** - 通过 WebSocket 将分析结果推送到手机

## 📋 工作流程

```
按下 Alt+Z 
    ↓
自动截图（保存到 ./screenshots/quick_*.png）
    ↓
调用 Kimi API 分析图片
    ↓
如果 WebSocket 已连接 → 自动发送到手机
如果 WebSocket 未连接 → 在界面显示结果，可手动发送
```

## 💡 使用方法

### 前提条件
1. 安装依赖：
   ```bash
   pip install openai>=1.0.0
   ```

2. 启动程序后，等待状态栏显示 "快速分析快捷键已启用 (Alt+Z)"

### 使用步骤
1. **确保 WebSocket 服务已启动**（可选，用于自动发送到手机）
   - 点击"启动 WebSocket 服务"按钮
   - 手机连接到显示的 WebSocket 地址

2. **按下 Alt+Z**
   - 程序会自动截图
   - 调用 Kimi 分析图片
   - 如果 WebSocket 已连接，结果会自动发送到手机
   - 同时在界面的"LLM 分析结果"区域显示

3. **查看结果**
   - 界面右侧"LLM 分析结果"区域显示分析内容
   - 右下角显示耗时（标记为 Kimi）
   - 状态栏显示整体耗时和发送状态

## 🔍 与原有功能的区别

| 特性 | 原有流程 (Alt+X) | 快速分析 (Alt+Z) |
|------|------------------|------------------|
| 触发方式 | Alt+X 截图 | Alt+Z 一键完成 |
| OCR 识别 | ✅ 需要 | ❌ 跳过 |
| LLM 分析 | ✅ 文本分析 | ❌ 不使用 |
| Kimi 分析 | ❌ 不使用 | ✅ 图片直析 |
| 步骤数 | 3步（截图→OCR→LLM） | 2步（截图→Kimi） |
| 速度 | 较慢 | 更快 |
| 适用场景 | 需要精确文字识别 | 快速面试答题 |

## 🐛 故障排查

### 问题1: Alt+Z 无响应
- 检查程序是否完全启动（等待状态栏提示）
- 确认没有其他程序占用 Alt+Z 快捷键
- 查看控制台是否有错误信息

### 问题2: Kimi API 调用失败
- 检查网络连接
- 验证 API Key 是否有效
- 查看控制台错误详情

### 问题3: 消息未发送到手机
- 确认 WebSocket 服务已启动
- 确认手机已连接（状态显示"✅ 已连接"）
- 检查手机 WebSocket 客户端是否正常

## 📝 注意事项

1. **API 费用**: Kimi API 调用会产生费用，请合理使用
2. **网络要求**: 需要稳定的网络连接访问 Kimi API
3. **图片大小**: 建议截图区域不要过大，以提高识别速度
4. **并发限制**: 避免频繁触发 Alt+Z，等待前一次分析完成
